Job Market Analyzer

Overview:

A data analysis application and an interactive dashboard for exploring data science job market trends,
including salary distributions, comparing experience level impact on salary and detecting outliers.

Features:

- Data cleaning and preprocessing pipeline
- CSV validation layer (Generic and CSV specific)
- Salary analysis (mean, median ,outliers count)
- Outlier detection (using IQR method)
- Interactive dashboard
- Different information filtering options
- Exporting filtered data as a CSV

Tech Stack:

- Python
- Pandas
- Streamlit
- Matplotlib
